# ALTRun Next Roadmap

## v0.1.x - Classic foundation

- Native Win32 x64/ARM64 application
- Alt+Space global activation
- Classic ALTRun-style compact launcher
- Keyboard-first selection and launch
- Custom commands
- Start Menu indexing
- Usage frequency / recency ranking
- Per-monitor DPI v2
- Portable local state
- Tray controls

## v0.2.x - Search engine

- Pinyin and pinyin-initial matching
- Improved fuzzy ranking
- Everything SDK integration
- Configurable search providers
- Windows Apps / MSIX / UWP indexing
- Custom hotkeys
- Legacy ALTRun.ini importer

## v0.3.x - Windows integration

- Explorer current-folder actions
- Open/Save dialog folder jump
- Total Commander integration
- Clipboard/search actions
- Calculator provider
- URL search aliases

## v0.4.x - Modern configuration center

- Separate settings window; launcher remains classic
- Command editor and groups
- Search source manager
- Hotkey editor
- Appearance editor
- Update channel settings

## v1.0 - Stable classic launcher

- Classic / Classic Dark themes
- Plugin/provider API
- Crash-safe atomic config writes
- Signed releases
- Auto updater
- Migration assistant
