# ALTRun Next v0.5.0 RC Validation

This is the release-candidate sign-off checklist for the frozen v0.5.0 feature set.

The existence of an RC tag means the automated build, test, package and release-contract gates passed. It does **not** mean the manual desktop observations below were completed. Stable promotion requires the mandatory real-world items to be observed on actual Windows desktops with no release-blocking defect.

Do not mark a checkbox as passed unless the stated behavior was actually observed.

## Frozen RC contract

The following are frozen throughout the v0.5.0 RC line:

- settings.json schemaVersion 3
- commands.json schemaVersion 1
- usage.json schemaVersion 1
- provider-cache.json schemaVersion 2
- provider IDs:
  - windows.startmenu
  - windows.packaged
  - windows.apppaths
  - windows.path
  - everything.filesystem
- Everything files/folders default: disabled
- Everything transport baseline: Unicode Query2 over WM_COPYDATA
- no bundled Everything executable or DLL
- no Everything SDK3/named-pipe runtime dependency
- Everything remains a Dynamic Query Provider and is not written to provider-cache
- Everything file/folder usage remains ephemeral and is not written to usage.json
- Classic launcher width 420 logical px
- Classic row height 16 logical px
- Classic visible result limit 10

Only regression fixes, compatibility fixes, data-safety fixes and publication/package fixes are allowed after RC1.

## Package and startup

- [ ] ALTRunNext-x64.zip extracts and starts from a normal user-writable folder.
- [ ] ALTRunNext-ARM64.zip contains the same portable file contract.
- [ ] Package VERSION exactly matches the RC tag.
- [ ] EXE FileVersion/ProductVersion exactly match the fixed Windows version derived from VERSION.
- [ ] SHA256SUMS.txt verifies both ZIP files.
- [ ] No unexpected runtime DLL is present.
- [ ] No Everything executable/DLL is bundled.
- [ ] CONFIG_SCHEMA.md, DESKTOP_VALIDATION.md, V0.5_RC_VALIDATION.md and EVERYTHING_COMPATIBILITY.md are present in both packages.
- [ ] Clean startup remains silent unless show-on-startup is enabled.
- [ ] data/ is created beside the executable and remains writable.
- [ ] Read-only data-directory behavior shows the existing warning without corrupting settings.

## Clean install and Settings schema 3

- [ ] Clean data creates settings.json schemaVersion 3.
- [ ] Start Menu, Windows Apps, App Paths and PATH default enabled.
- [ ] Everything files & folders defaults disabled.
- [ ] Enabling Everything persists across restart.
- [ ] Disabling Everything immediately returns search to static-only mode.
- [ ] Settings > Search Sources shows current Everything IPC diagnostics without changing launcher geometry.

- [ ] commands.json and usage.json remain usable because their schemas stay at version 1.

- [ ] Unicode filenames/paths are preserved.
- [ ] Exact File/Folder results participate in unified ranking.

## Everything 1.5 current beta

- [ ] Current Everything 1.5 beta default/unnamed instance is reported as IPC available.
- [ ] Query2 results match representative Everything searches.
- [ ] Rapid typing never flashes an older query generation into the final visible list.
- [ ] Starting Everything after ALTRun Next recovers without restarting ALTRun Next.
- [ ] Stopping Everything falls back without hanging the launcher.
- [ ] Restarting Everything recovers on a later query.
- [ ] Search Sources displays the actual IPC endpoint used.

## Named and multiple Everything instances

- [ ] With no unnamed instance and exactly one named instance, ALTRun Next auto-selects the named IPC endpoint.
- [ ] Search Sources identifies that a unique named instance was auto-selected.
- [ ] With two or more named instances and no unnamed instance, ALTRun Next reports ambiguity.
- [ ] Ambiguous named instances do not cause ALTRun Next to pick a random Everything database.
- [ ] Static application/user-command search remains fully usable during ambiguous fallback.
- [ ] When an unnamed/default instance is present together with named instances, the unnamed/default instance takes precedence.

## Everything unavailable / Lite

- [ ] Enabling Everything with no Everything installation/runtime shows an actionable “Everything not detected” message instead of raw system error 2 as the primary diagnosis.
- [ ] Get Everything opens the official voidtools download page in the default browser.
- [ ] Recheck immediately refreshes the status after Everything is started, without restarting ALTRun Next.
- [ ] Enabling Everything while Everything is stopped reports the fallback state clearly.
- [ ] Application-search fallback remains responsive.
- [ ] Everything Lite is treated as IPC unavailable.
- [ ] ALTRun Next never starts Everything automatically.
- [ ] ALTRun Next never displays a modal error simply because Everything is unavailable.

## Paths and shell execution

- [ ] Drive-root Folder result such as C:\ opens correctly and shows no fabricated parent path.
- [ ] UNC file result remains intact and opens through the Windows shell.
- [ ] UNC folder result remains intact and opens through the Windows shell.
- [ ] Extended-length \\?\ paths remain intact through search/result construction.
- [ ] Paths containing Chinese characters, spaces and punctuation remain intact.
- [ ] A file with no explicit full-path field is reconstructed correctly from parent + name when returned by the protocol.

## Ranking and mixed-result regression

- [ ] Exact user command remains strong against similarly named dynamic results.
- [ ] Exact application remains strong against a weak file fuzzy match.
- [ ] Exact filename can outrank a weak/fuzzy application match.
- [ ] Duplicate target suppression is case-insensitive.
- [ ] Folder rows retain the established Classic compact cue.
- [ ] File/Folder preview shows the direct full target path.
- [ ] No result row extends or changes the frozen Classic geometry.

## Immediate execution and input safety

Enable Everything and single-result immediate execution.

- [ ] Immediate execution waits for the current dynamic generation to settle.
- [ ] Hiding the launcher cancels deferred automatic execution.
- [ ] Manually executing a result prevents a late Everything reply from launching another item.
- [ ] IME composition never triggers immediate execution before commit.
- [ ] Canceling IME composition does not leave a stale pending state.
- [ ] Holding a numeric quick-launch key launches at most once per physical press.
- [ ] Numpad and main-row numeric behavior remain consistent.

- [ ] General Launcher/Search behavior rows show title and description on separate lines with no overlap at every DPI.
- [ ] Shortcut editor labels remain single-line; the Chinese aliases label does not wrap into the next field.
- [ ] Shortcut editor Enabled/Admin/Pinned controls stay inside the field column without overlap.
- [ ] Shortcut editor Test/Delete/Discard/Save buttons remain separated at the minimum supported Settings width.
- [ ] Search Sources diagnostics do not overlap Get Everything/Recheck or the explanatory note.
- [ ] Search Sources cards and General cards align with the page-header content gutter.
- [ ] Sidebar active-page styling uses the accent bar/background consistently with no native boxed-button artifact or text bullet.
- [ ] Classic launcher remains 420 logical px wide.
- [ ] Classic result rows remain 16 logical px high.
- [ ] Classic shows at most 10 result rows.
- [ ] Filename and parent-path columns do not overlap critical controls.
- [ ] Search Sources Everything row remains readable.
- [ ] Search Sources diagnostics do not overlap or clip at normal Settings widths.
- [ ] Moving between monitors with different DPI does not strand the launcher or Settings outside the work area.
- [ ] Simplified Chinese and English labels remain usable.

## Long-run soak

Run the RC for at least one normal interactive session with Everything enabled.

- [ ] Repeated launcher open/hide cycles keep the global hotkey functional.
- [ ] At least 500 representative searches complete without a UI hang.
- [ ] Repeated rapid typing does not accumulate stale result flashes.
- [ ] Stop/start Everything at least 10 times; fallback/recovery remains functional.
- [ ] Open/close Search Sources repeatedly; diagnostics continue refreshing only while appropriate.
- [ ] Memory use does not show obvious unbounded growth during the session.
- [ ] CPU returns to idle after search activity stops.
- [ ] No unexpected ALTRun Next crash or Everything crash is observed.

## Stable promotion gate

Do not promote v0.5.0 stable unless all of the following are true:

- [ ] All mandatory Windows 10/11 x64 environments above were executed.
- [ ] Everything 1.4 and current Everything 1.5 beta were both observed on real installations.
- [ ] Schema migration and downgrade protection were observed on real portable data.
- [ ] No release-blocking defect remains open.
- [ ] Final RC package hashes were recorded and verified.
- [ ] Any known non-blocking issue is documented with scope/workaround.
- [ ] Stable promotion is made from the validated RC code line without adding features.
