# ALTRun Next v0.7.0 RC Validation

This checklist is the release gate for `v0.7.0-rc.1` and the basis for promoting the same frozen contract to `v0.7.0` Stable.

## Release Freeze & Upgrade Gate

RC1 is a release-freeze build. It must not add a new user-facing feature, persisted schema, Provider ID, Hotkey action ID, package helper name, update behavior, uninstall ownership rule, or Managed Everything lifecycle rule.

## 7. Managed Everything lifecycle freeze

Managed installation:

- [ ] Managed client runs headless/no-tray.
- [ ] Owned service remains Running + AUTO_START while the provider is enabled.
- [ ] Normal ALTRun Next exit closes the managed client but leaves the owned service warm.
- [ ] Restart reconnects without unnecessary UAC.

Explicit provider disable/enable:

- [ ] Disable stops the managed client and disables only the ALTRun-owned service.
- [ ] Reboot does not restart an explicitly disabled owned service.
- [ ] Re-enable restores AUTO_START, starts the owned service/client and restores search.
- [ ] Cancelling UAC preserves the previous provider state.

External Everything:

- [ ] External/user-installed Everything is never stopped, disabled, reconfigured, retargeted or uninstalled by ALTRun Next.

## 8. Native Uninstall freeze

Preserve-data mode:

- [ ] Exact ALTRun Next process is closed.
- [ ] ALTRun-owned Managed Everything state is removed when present.
- [ ] External Everything remains untouched.
- [ ] User `data/` remains available for reinstall/recovery.

Full-remove mode:

- [ ] UAC is requested before destructive cleanup.
- [ ] Cancelling UAC leaves Explorer location unchanged.
- [ ] Explorer release uses the validated normal-integrity broker path.
- [ ] The elevated worker owns the destructive root DELETE lease.
- [ ] Root lease is acquired before deleting installation-tree entries.
- [ ] Child cleanup remains entry-by-entry and synchronous.
- [ ] Final root deletion uses the already-held directory handle.
- [ ] No reboot-delete fallback is used.
- [ ] A true lock reports the real failing path/error and Restart Manager owner information when available.
- [ ] Repeated full-remove test has no error 1460, no Explorer-release failure, no residual empty root and no reboot requirement.

## 11. Stable promotion gate

Do not change the frozen runtime contract between RC1 and Stable unless a release-blocking regression requires a focused fix.

Before promoting to `v0.7.0`:

- [ ] RC1 real-Windows validation has no release blocker.
- [ ] Native `beta.12 -> rc.1` update is confirmed.
- [ ] Version ordering remains `beta.12 < rc.1 < stable`.
- [ ] Stable-channel update from RC1 to `v0.7.0` is verified when the Stable package exists.
- [ ] Stable promotion changes release metadata/version only unless a blocker was found.
- [ ] Any blocker fix receives focused regression coverage before Stable.

RC exit criterion: all release-critical checks above pass, with no data-loss, ownership, update, uninstall, provider-dedup, hotkey, schema, or platform blocker.
