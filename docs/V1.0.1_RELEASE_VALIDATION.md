# Asterun 1.0.1 Release Validation

Asterun 1.0.1 is a focused maintenance release for tray identity, hotkey-conflict startup behavior and the approved transparent application/tray artwork.

## Frozen release contract

- Version: `1.0.1`
- Windows fixed FileVersion/ProductVersion: `1.0.1.30000`
- Settings schema: 11
- Commands schema: 2
- Usage schema: 2
- Provider Cache schema: 22
- Architectures: x64 and ARM64
- Stable package layout unchanged

## Required automated gates

- version metadata and release-contract verification;
- Core Release-mode tests;
- Windows 10 API compatibility build and smoke;
- x64 and ARM64 production package builds;
- Windows desktop/runtime smoke;
- packaged executable icon verification;
- runtime regression for a primary-hotkey conflict while the tray icon remains configured visible.

## v1.0.1 regression acceptance

The release is accepted only when all of the following hold:

- Asterun uses a tray GUID distinct from the former ALTRun Next product identity.
- Starting Asterun while another application owns one or more configured global hotkeys does not terminate Asterun.
- Startup hotkey conflicts are reported once rather than through multiple dialogs.
- Asterun remains reachable through its tray icon after the conflict warning is dismissed.
- A failed initial tray registration clears a stale Asterun shell entry and retries once.
- Explorer taskbar recreation restores the configured persistent Asterun tray icon.
- The application and tray icons use the approved transparent Asterun mark with no square background.
